# LaneWise by SM Retail — brand reference

Read-only source material for the design system. The interactive brand doc "LaneWise by SM Retail — Brand and design system v0.5" is the source of truth for tokens; the style-guide docs (SG-002/003/004/007/009) restate it in the repo's doc format.

- Product name: **LaneWise by SM Retail** (endorsed sub-brand; never the SM logo itself).
- Design language: square corners (radius 0), no shadows, no gradients; solid fills reserved for the single primary action, the key number and the most urgent status; everything else a **2px outline (never a hairline)**.
- Token namespace: `--lw-*`.
- Status: working design system of record for the build, **pending SM brand + legal sign-off** (see risks in GOV-003 and open question in GOV-005).

Add the exported files when available: `lanewise_tokens.css`, `lanewise_logo.svg`, `lanewise_logo_reversed.svg`, `lanewise_icon.svg`.
